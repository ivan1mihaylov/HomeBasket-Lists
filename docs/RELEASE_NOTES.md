The card's **List** setting is a picker now, filled with the lists that
actually exist, instead of a field you had to type a name into.

It stores the list rather than its name, so renaming a list no longer points
the card at the wrong one. A value saved before this — or one whose list has
since been removed — is kept as an option of its own rather than silently
swapped for another list.

**Language** is a picker too: Home Assistant's language, Български, or English.
