**A suggestion is taken when the finger is lifted, not when it lands.**

Picking happened the moment a finger touched a suggestion, so the row that was
added was the one first touched — and a finger that lands slightly low and
slides onto the row it meant added the row below it. The row under the point
where the touch ends is the one taken now; letting go somewhere else takes
nothing, the way every other button behaves.

The list is also no longer redrawn when the same products come back, so the
rows do not move about while you are reaching for one.
